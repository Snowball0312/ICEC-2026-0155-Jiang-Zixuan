## 三、项目 03 · 基于手机内置传感器的日常旋转机械/电器异常声振诊断仪

目录：[`项目03_日常旋转机械电器异常声振诊断仪/`](项目03_日常旋转机械电器异常声振诊断仪/)

| 目录 | 内容 |
|---|---|
| `01_原始声振数据/` | 5 工况 14 段 WAV 原始录音（48 kHz / 24 bit，20 s/段）、3 张实验照、采集记录与采集手册 |
| `02_可视化图/` | 波形对比、频谱对比、包络谱、特征散点、混淆矩阵、抗噪曲线（各含 SVG + PNG） |
| `03_特征与模型/` | 32 维特征表、逐折验证、档内对照、混淆矩阵、分类报告、模型参数、抗噪曲线 |
| `04_分析脚本/` | 特征提取、训练、盲测、抗噪、数据体检、档位核查、出图、一键流水线（12 个脚本，零第三方依赖） |
| `05_盲测与抗噪/` | 7 段现场盲测录音、档位验证录音、盲测结果表（含录屏列）、录屏脚本；`现场录屏/盲测01–07.mp4`（131 MB，含时间戳／纸条／音轨三重复核说明） |
| `06_诊断报告/` | 诊断报告（14 节 + 3 附录） |

**核心结果**：被测对象为手持小风扇（扇面 5 cm、3 档、不可拆机），用「档位 × 遮挡程度」构造 5 种气动工况
（无遮挡基准 L0 + 半/全遮挡 × 一/二档）。0.5 s 窗、50% 重叠、32 维特征、收缩 LDA，
按轮次 GroupKFold 三折：窗口级 **99.86%**、整段级 **100%**、宏 F1 **0.9986**。
叠加白噪声 20 dB 以内 100%、15 dB 75%、12 dB 50%、10 dB 及以下失效；粉噪 12 dB 以内 100%。
7 段现场盲测中**遮挡方式 7/7 判对、档位错 1 次**，且这批盲测查出建档 L2/L3 两组标签贴反并已订正
（订正后准确率不变，说明只换了名称、未动样本）。

> 采集口径与作业要求的差异（双模态未执行、14 段对 15 组、遮挡替代拆装类故障、盲测由本人设置、
> 无绝对声压级校准）全部写在报告第 1.1 节，未作隐瞒。

## 四、复现说明

三个项目均可在本地复现，无需安装第三方库：

```bash
# 课题08：重新分析四份 CSV 并导出图表
cd 课题08_多姿态步态加速度特征采集与对比/04_分析脚本
python analyze_acceleration.py

# 课题10：对某一组样本执行批量改名
cd 课题10_日常数字任务耗时审计与AI批处理实证/02_AI脚本与Prompt
python batch_rename.py "../01_任务样本/样本原始文件/sample-01" --log ./log

# 项目03：重跑全流程（特征 → 训练 → 抗噪 → 出图），约 11 分钟
cd 项目03_日常旋转机械电器异常声振诊断仪/04_分析脚本
python run_all.py

# 项目03：对单段录音出结论
python predict.py "../05_盲测与抗噪/现场录音/盲测07.wav"
```

运行环境：Python 3.9+（实测 3.13），Windows / macOS / Linux 均可。
