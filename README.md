## 一、课题 08 · 多姿态步态加速度特征采集与对比

目录：[`课题08_多姿态步态加速度特征采集与对比/`](课题08_多姿态步态加速度特征采集与对比/)

| 目录 | 内容 |
|---|---|
| `01_原始CSV波形数据/` | 4 份 Phyphox 原始 CSV：静止、平地慢走、上下楼梯、快跑 |
| `02_可视化图/` | 四状态加速度波形图、四状态阈值分布图（各含 PNG + SVG） |
| `03_阈值规则/` | 阈值规则说明、活动统计汇总、逐窗口特征明细、混淆矩阵、上下楼梯分段 |
| `04_分析脚本/` | 分析脚本与出图脚本（Python 标准库，零第三方依赖） |
| `05_分析报告/` | 多姿态步态加速度分析报告.docx |

**核心结果**：采样率 200 Hz，1 秒窗口平均幅值为特征 M，取 3 窗滑动中值后判决。
三条阈值 0.408 / 1.600 / 3.820 m/s²，124 个有效窗口命中 123 个，整体准确率 99.2%。

## 二、课题 10 · 日常数字任务耗时审计与 AI 批处理实证

目录：[`课题10_日常数字任务耗时审计与AI批处理实证/`](课题10_日常数字任务耗时审计与AI批处理实证/)

| 目录 | 内容 |
|---|---|
| `01_任务样本/` | 10 组 × 12 份 = 120 份样本、标准答案、人工组操作手册 |
| `02_AI脚本与Prompt/` | 主体脚本 + 样本生成 + 计时 + 核验脚本，附可复现提示词 |
| `03_耗时对比表/` | 5 个工作表的 Excel，以及逐轮原始测量数据 |
| `04_人机校验规则/` | 7 条判据、执行顺序、逐条实测验证结果 |
| `05_实证报告/` | 课题10_实证报告.docx（含附录样本与代码节选） |

**核心结果**：采样任务为报销票据批量改名（`YYYYMMDD_类别_金额.txt`，原地改名）。
人工组由本人实测，单组均值 222.03 s；AI 组单组中位 0.2422 s，整体提速约 917 倍。
准确率人工 90.8%（120 份错 11 处，均为误触/没点中等执行层手误），AI 100%（120/120）。
按搭建成本 30 分钟计，约 8.1 批回本。

## 三、复现说明

两个课题均可在本地复现，无需安装第三方库：

```bash
# 课题08：重新分析四份 CSV 并导出图表
cd 课题08_多姿态步态加速度特征采集与对比/04_分析脚本
python analyze_acceleration.py

# 课题10：对某一组样本执行批量改名
cd 课题10_日常数字任务耗时审计与AI批处理实证/02_AI脚本与Prompt
python batch_rename.py "../01_任务样本/样本原始文件/sample-01" --log ./log
```

运行环境：Python 3.9+（实测 3.13），Windows / macOS / Linux 均可。
