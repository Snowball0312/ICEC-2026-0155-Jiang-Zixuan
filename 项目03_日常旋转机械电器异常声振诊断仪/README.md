# 项目 03 · 基于手机内置传感器的日常旋转机械/电器异常声振诊断仪

用一部手机的**麦克风**采集**手持小风扇**在 5 种工况下的声音信号，
提取时域 / 频域 / 频带 / 谐波 / 包络共 32 维特征，用收缩 LDA 判别工况，
按"轮次"做 GroupKFold 交叉验证、按"档位"做档内对照，再用抗噪曲线和现场盲测证明它不是过拟合。

> **关于模态**：系统设计上支持声音 + 振动双通道，本次受采集端限制，实际以**声学单模态**完成。
> 原因有二：本机 Phyphox 精简版无「运动」实验，无法导出加速度；且实测叶片通过频率为
> **661–1386 Hz**，远超手机加速度计带宽（50–100 Hz），该通道只能看见电机基频。
> 代码保留 `--modality vib` 通路，数据补齐后无需改动即可启用。

全部代码**零第三方依赖**（只用 Python 标准库）。

## 一、五种工况

被测对象是**手持小风扇**（扇面 5 cm、3 档风速、一体注塑、不可拆机），因此不做拆机类故障，
而是在"气动通路"上做手脚：**档位 × 遮挡程度** 的组合，加一个无遮挡基准，共五种工况：

| 码 | 工况 | 档位 | 程度 | 制造方法（不拆机） | 本次实测 |
|---|---|---|---|---|---|
| L0 | 正常 | 1 / 2 档 | 0 | 纸片全部移出视场 | BPF 1106 / 1219 Hz |
| L1 | 一档半遮挡 | 1 档 | 半 | 一张纸片斜盖住扇面一侧 | BPF 661–677 Hz |
| L2 | 一档全遮挡 | 1 档 | 全 | 同一纸片折起挡满，四角轻贴留 3–5 mm 缝 | BPF 1074–1090 Hz |
| L3 | 二档半遮挡 | 2 档 | 半 | 同 L1 摆放，只按档位键 | BPF 746–749 Hz |
| L4 | 二档全遮挡 | 2 档 | 全 | 同 L2 摆放，只按档位键 | BPF 1189–1386 Hz |

为什么不做"进风侧 / 出风侧"的位置因子：真机测试发现纸片贴哪一面，人手难以稳定复现，
同名义工况的两段录音会落到不同位置——这正是最初几批标签对不上的根源。
改成"档位 × 程度"后，同程度的两类共用同一张照片、同一套摆放，类内一致性从"看运气"变成"可核对"（三段 BPF 极差 ≤ 2.4%）。

**L0 不参与训练**，只作基准：它只有 2 段且分属两档、谱形完全不同，作为一类进入 LDA 会把组内协方差撑开，
导致含 L0 的那一折整体塌陷（实测准确率 0.25）。详见 `06_诊断报告/诊断报告.md` 第 9.3 节。

详细操作见 [`01_原始声振数据/00_工况定义与采集方案.md`](01_原始声振数据/00_工况定义与采集方案.md)。

## 二、技术路线

```
录音机 WAV ─→ 分帧（0.5 s / 50% 重叠）→ 32 维特征 → 收缩 LDA → 整段投票 → 工况 + 置信度
                                                              ↑
                                                      按轮次 GroupKFold
                                                      档内半/全遮挡二分类（检验同档位内是否仍可分）
```

**特征构成（32 维）**

| 类别 | 维度 | 具体量 |
|---|---|---|
| 时域 | 9 | RMS、峰值、峰峰值、波峰因子、峭度、偏度、过零率、脉冲因子、裕度因子 |
| 频域 | 8 | 谱质心、谱带宽、85% 滚降、谱平坦度、谱熵、谱通量、谱斜率、主频 |
| 频带 | 8 | 0–125 / 125–250 / … / 8k–16k Hz 八段能量占比（`--modality vib` 时为 0–120 Hz 八段） |
| 谐波 | 4 | BPF、1× / 2× / 3× 谐波能量占比 |
| 包络 | 3 | 包络 RMS、包络波峰因子、包络谱主频 |

基频锚定用 **BPF（叶片通过频率）** 而不是转子基频：手机麦克风在 50 Hz 以下几乎无响应，
而 BPF 在 661–1386 Hz 稳定高出噪底 16 dB，是更可靠的锚点（`F0_RANGE = (350, 1600)` Hz）。

## 三、防止"假高分"的三个设计

1. **按轮次分组交叉验证**：同一轮的窗口整轮进、整轮出。随机切分会让重叠窗口跨集，准确率虚高。
2. **窗口投票而非单窗判决**：一段 20 s 录音切出约 59 个窗，按后验概率累加投票，
   输出"结论 + 置信度 + 各类占比"，低置信度时提示复测。
3. **档内二分类对照**（`cv_同档遮挡.csv`）：四类 = 档位 × 遮挡，档位写在标签里，
   模型可以只靠转速判档。因此在每个档位内部单独建"半遮挡 vs 全遮挡"二分类器，
   原意是让转速差异被压到最小、只能靠谱形判决。**实测与预设相反**：同档位内两类转速差 60%，
   比跨档位的 10% 还大——遮挡方式本身就决定转速（报告 5.2 节）。这项对照因此没能否定"靠转速"，
   但它证明了同档位内仍然可分（99.72% / 100%），并把结论边界钉死：
   只能说"遮挡可判"，不能说"判据与转速无关"（报告 10.5 节）。

## 四、核心结果

| 指标 | 声学单模态 |
|---|---|
| 数据规模 | 14 段 WAV / 822 个分析窗（704 窗进分类器，L0 的 118 窗作基准） |
| 窗口级准确率（3 折 GroupKFold） | **99.86%** |
| 整段级准确率（窗口投票） | **100%** |
| 宏平均 F1 | **0.9986** |
| 档内对照：一档 L1 vs L2 / 二档 L3 vs L4 | 99.72% / 100%　、　100% / 100%（整段均 100%） |
| 抗噪（白噪声） | 20 dB 以内 100%，15 dB 75%，12 dB 50%，10 dB 及以下 25% |
| 抗噪（粉噪声） | 12 dB 以内 100%，10 dB 50%，5 dB 及以下 25% |

混淆矩阵只有一处误差：1 个 L2 窗被判成 L1（同档位、遮挡程度判反），整段投票后不影响结论。

另有两条边界必须一起读，否则上面的数字会被误读：

- **只有 BPF 一维时**，整段仍为 100%、窗口降到 92.33%——本数据的"遮挡"与"转速"高度共线（报告 10.5 节）；
- **白噪 12 dB 以下失效**，本质是谱平坦度／质心被平谱拖走，属特征不具噪声不变性（报告 12.3 节）。

## 五、复现

```bash
cd 04_分析脚本

# 0）没有真实数据时，先验证管线本身没问题（合成信号，约 1 分钟）
python selftest.py

# 0.5）数据齐了以后：一条命令跑完体检→特征→训练→抗噪→出图
python run_all.py

# 1）数据体检：段数、命名、配图、削波、静音
python check_dataset.py --expect 3

# 2）特征提取（当前数据只有 WAV，默认音频模态）
python features.py
# 若日后补齐加速度 CSV，可加 --modality vib 单独提振动

# 3）训练 + 按轮次 GroupKFold + 档内半/全遮挡对照
python train.py --modality audio --baseline L0

# 4）单段盲测
python predict.py ../01_原始声振数据/L2_一档全遮挡/L2_一档全遮挡_r03_g1_12cm_1122_1427.wav

# 5）抗噪曲线（默认按 CPU 核数并行，32 核约 4 分钟一轮）
python robustness.py --noise white --snrs clean,30,25,20,15,12,10,5,0,-5

# 6）出图（6 张 SVG，加 --png 同时转 PNG）
python plot_figs.py --png
```

运行环境：Python 3.9+（实测 3.13），Windows / macOS / Linux 均可，无需 `pip install`。

缺了轮次信息，脚本会把该文件归入 `r00` 并降低分组有效性；缺了档位则跳过档内对照。

## 七、局限与后续

- **与任务要求的采集口径差异**：要求为"麦克风 + 加速度计、5 工况 × 15 组、他人设工况"，实际为
  声学单模态、14 段（基准少 1 段）、7 段盲测由本人设置。四处差异的原因与影响逐条写在报告 **1.1 节**，
  含 12/15 cm 两种量法、未做声压级校准（只报 dBFS）两项口径说明。
- **振动通道未采集**：本机 Phyphox 精简版无加速度实验；实测 BPF 为 661–1386 Hz，远超加速度计带宽
  （50–100 Hz）。系统保留双模态通路，结论的适用范围是**声学单模态**。
- 五种工况都落在**通风受阻**这一故障族内，不含轴承点蚀、扇叶失衡等结构性故障；
- **遮挡方式决定转速，档位只是小量**：半遮挡（纸片被吸住贴叶）使转速下降 38%，全遮挡（进气口封死）几乎回到自由态（−2% ~ +14%）；
  同一遮挡状态下换档只差 10–12%。因此"挡得越严转速越低"是错的，决定转速的是"纸片会不会碰到叶片"。
- **"遮挡"与"转速"在本数据上不可分离**：同档位内两类转速差 60%，单用 BPF 一维即可达整段 100%、窗口 92.33%
  （32 维为 99.86%）。所以本实验证明"遮挡可判"，**不能**证明"判据与转速无关"。
- **档位标称翻过一次车**：靠数按键记档位导致 L2 与 L3 两组标签整体贴反，由 7 段盲测查出并已订正（报告 5.4 节）；
  可复现的做法是每段先录 2 s 按键瞬态，事后数瞬态定档。
- **抗噪能力弱**：白噪 12 dB 以下失效，可用边界约 20 dB；粉噪因能量集中在低频，边界可放宽到 12 dB；
- 单一设备型号、单一房间内采集，跨设备泛化未验证。
- 可扩展：补齐振动通道做决策级融合、特征集做噪声鲁棒性筛选、把模型压缩到手机端实时推理。
