# 03_特征与模型

本目录所有文件都由脚本生成，不要手工编辑——重跑脚本会覆盖。

| 文件 | 生成方式 | 内容 |
|---|---|---|
| `features.csv` | `python features.py` | 逐窗特征表（822 行），每行一个 0.5 s 分析窗，含 modality/condition/group/gear 标签 |
| `model.json` | `python train.py --baseline L0` | 收缩 LDA 参数、标准化均值方差、类别列表、特征顺序 |
| `cv_folds.csv` | 同上 | 逐折：训练/测试窗数、LDA 与 kNN 窗口准确率、整段准确率 |
| `cv_同档遮挡.csv` | 同上 | 同档位内「半遮挡 vs 全遮挡」二分类，用于检验档位固定后两类是否仍可分（结论：可分，但转速并未被剥离） |
| `混淆矩阵_窗口.csv` | 同上 | 真实类别 × 预测类别交叉表 |
| `分类报告.csv` | 同上 | 每类精确率、召回率、F1 与宏平均 |
| `训练摘要.md` | 同上 | 可直接粘进诊断报告的结果段（含档内对照表） |
| `抗噪曲线.csv` | `python robustness.py` | 白噪声每档 SNR 的整段准确率与逐类准确率 |
| `抗噪报告.md` | 同上 | 白噪声的抗噪结论段（含自动判断的优势/局限表述） |
| `抗噪曲线_粉噪.csv` | `python robustness.py --noise pink` | 粉噪声每档 SNR 的整段准确率与逐类准确率 |
| `抗噪报告_粉噪.md` | 同上 | 粉噪声的抗噪结论段，与白噪对照用 |
| `数据集体检.md` | `python check_dataset.py --expect 3` | 段数、命名、配图、削波、静音的检查结果 |
| `一键结果.md` | `python run_all.py` | 全流程关键数字汇总，可直接誊进报告 |

## 本次实际数字（2026-11-22）

| 指标 | 数值 |
|---|---|
| 数据规模 | 14 段 WAV / 822 个分析窗，其中 704 窗进分类器（L0 的 118 窗作基准） |
| 窗口级准确率（3 折） | 99.86% |
| 整段级准确率（窗口投票） | 100% |
| 宏平均 F1 | 0.9986 |
| 档内对照 | 一档 L1 vs L2：99.72% / 100%；二档 L3 vs L4：100% / 100% |
| 单特征消融（仅 BPF 一维） | 窗口 92.33%，整段 100% |
| 抗噪（白噪） | 20 dB 以内 100%，15 dB 75%，12 dB 50%，10 dB 及以下 25% |
| 抗噪（粉噪） | 12 dB 以内 100%，10 dB 50%，5 dB 及以下 25% |

> `cv_同档遮挡.csv` 取代了早期的「留一档位验证」。原因：现在的 4 类本身就是
> 档位 × 遮挡的组合，留出某个档位后训练集里就没有该档的三个类别，验证无从谈起。
>
> 需说明的是，档内二分类**并未**达到设计初衷。原意是固定档位、压住转速，只留谱形差异；
> 实测同档位内两类转速差达 60%，因为"遮挡方式"本身就决定转速（报告 5.2 节）。
> 它最终证明的是"同档位内仍然可分"（99.72% / 100%），而非"判据与转速无关"；
> 仅用 BPF 一维即可取整段 100%、窗口 92.33%，这条边界写在报告 10.5 节，不回避。
